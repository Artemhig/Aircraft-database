Detailed Description

Центральный класс-контейнер и фасад для всей системы

Отвечает за:

  • Хранение и управление коллекциями самолётов и маршрутов
  • Отслеживание активных полётов
  • Сохранение и загрузку данных из файлов (aircrafts.txt, routes.txt)
  • Всю бизнес-логику: отправка рейсов, обновление времени, отображение статусов
